# Zenn 用画像

このフォルダの画像は Zenn の「GitHub リポジトリ連携」でアップロードされます。

- **配置**: リポジトリ直下の `/images`（このフォルダ）
- **参照**: 記事内で `![](/images/ファイル名.png)` のように絶対パスで指定

## 記事「複数リポジトリに copilot-instructions を自動同期する」で使用

| ファイル名 | 説明 |
|-----------|------|
| `sync-workflow.png` | Actions タブでワークフローが起動しているスクリーンショット |
| `sync-pr-created.png` | 対象リポジトリに PR が自動作成されたスクリーンショット |

Qiita などからスクリーンショットを保存するか、同様の画面をキャプチャして上記のファイル名でこのフォルダに配置してください。（3MB 以内、.png / .jpg / .jpeg / .gif / .webp）
